# VK Music Bot

Telegram бот для поиска и скачивания музыки из VK, Spotify и YouTube.

## Возможности

- 🔍 Поиск треков по названию/исполнителю
- 🎵 Распознавание музыки (Shazam)
- ⬇️ Скачивание аудио
- 🎧 Поддержка VK, Spotify, YouTube

## Быстрый старт

```bash
# Установка зависимостей
pip install -r requirements.txt

# Настройка окружения
cp .env.example .env
# Отредактируйте .env

# Запуск бота
python -m bot
```
