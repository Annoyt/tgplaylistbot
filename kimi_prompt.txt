## 1. Обзор проекта

Платформа состоит из трёх частей:
1. **Web-приложение** (FastAPI) — погодный дэшборд + защищённая админка
2. **Telegram MusicBot** (aiogram 3) — поиск/распознавание/скачивание музыки
3. **Telegram WeatherBot** — placeholder на будущее

## 2. Стек технологий

- Backend: FastAPI, Jinja2, uvicorn
- Auth: JWT (PyJWT) + bcrypt, httpOnly cookies
- DB: SQLite + aiosqlite (НЕ хранить треки! Zero server storage)
- Weather: OpenWeatherMap API через httpx
- Bot: aiogram 3.x (async)
- Music: yt-dlp, vk_api (VkAudio), spotipy
- Recognition: shazamio (primary) + pyacoustid (fallback)
- Audio: ffmpeg (system), pydub
- Config: pydantic-settings из .env

## 4. Детальные спецификации

### 4.1 Weather Dashboard (index.html)

ПУБЛИЧНАЯ страница, без авторизации.

**Два блока локаций рядом**:
- 📍 «Моё местоположение» — navigator.geolocation → reverse geocode
- 🔎 «Выбранная локация» — поле ввода с autocomplete

**Карточки в каждом блоке**:
1. 🌡 Текущая погода (температура, влажность, ветер, иконка)
2. 🫁 Качество воздуха AQI (индекс 1-5, PM2.5, PM10, O₃, NO₂, цветовая шкала)
3. 🌧 Шанс дождя % + поминутный прогноз на 1ч + 48ч
4. 📅 Календарь-прогноз с переключателем [7д] [14д] [Месяц]
5. 📜 Архив погоды — datepicker → исторические данные за прошлые годы

**Дизайн**: ОБЯЗАТЕЛЬНО тёмная тема, glassmorphism карточки, градиенты по типу погоды (солнечно = тёплый градиент, дождь = холодный), плавные анимации, Google Fonts (Inter/Outfit). НЕ ДЕЛАТЬ примитивный вид.

### 4.2 Auth

- Один admin-пользователь (login/password из .env)
- POST /login → проверка bcrypt → JWT в httpOnly cookie (24h)
- GET /logout → удаление cookie
- Middleware: /admin/* → проверка cookie → 307 на /login если невалидный

### 4.4 Telegram MusicBot — Поиск

Пользователь отправляет текст → бот ищет **ОДНОВРЕМЕННО** на YouTube, VK, Spotify (asyncio.gather) → объединяет результаты.

**Формат выдачи (10 штук на странице)**:
```
🔍 <запрос>
Результаты 1-10 из N

1. Artist – Title 5:14 ▶️YT 7.2M 192k
2. Artist – Title 8:38 🎵VK 9.1M 320k
3. Artist – Title 7:16 🟢SP 16.3M 318k
...
10. Artist – Title 3:04 🎵VK 4.4M 201k
```

**Inline keyboard под списком**:
Ряд 1: [◀️] [1] [2] [3] [4] [5] [▶️]   — пагинация
Ряд 2: [6] [7] [8] [9] [10]
Ряд 3: [BR: ↑] [Lossless: ❌] [Title]   — фильтры/сортировка
Ряд 4: ❤️ 🔥 😢 🎉                      — отправить в топик-плейлист

**Нажатие на номер трека** → новое сообщение с деталями + кнопки:
[⬇️ MP3 320] [⬇️ FLAC]

**Скачивание** → бот отправляет «⏳ Скачиваю...» → скачивает через yt-dlp/vk_api → send_audio → удаляет файл с сервера.

### 4.5 Telegram MusicBot — Распознавание

Бот принимает ЛЮБОЙ из этих типов сообщений:
- 🎤 voice (ogg) → конвертировать в WAV
- 🔵 video_note (mp4) → извлечь аудио
- 🎬 video (пересланные клипы) → извлечь аудио
- 🔗 URL-ссылка (Instagram, TikTok, Twitter и т.д.) → yt-dlp download → извлечь аудио
- 🎵 audio файл → напрямую

Pipeline: входной файл → ffmpeg → WAV → shazamio → если не нашёл → pyacoustid → RecognizedTrack → автоматический поиск "{artist} {title}" на всех платформах → стандартный формат выдачи.

### 4.6 Telegram MusicBot — Плейлисты через Forum Topics

**ПРИНЦИП: ZERO SERVER STORAGE.** Треки отправляются в Telegram и удаляются с сервера.

**При добавлении бота в группу с топиками**:
1. Бот АВТОМАТИЧЕСКИ создаёт топики: ❤️ Избранное, 🔥 Энергия, 😢 Для души, 🎉 Вечеринка, 💬 Поиск
2. Пользователи могут ПЕРЕИМЕНОВАТЬ топики — бот ориентируется на ИКОНКУ-ЭМОДЗИ, не на название

**Маршрутизация треков**:
- Нажатие ❤️ → бот находит топик с иконкой ❤️ → скачивает трек → send_audio в этот топик → удаляет файл
- Нажатие 🔥 → аналогично в топик 🔥
- Нажатие НЕИЗВЕСТНОГО эмодзи (нет такого топика) → бот спрашивает: «Создать топик 🤘? [Да / Нет]». Да → создаёт + отправляет. Нет → игнорирует.

**Голосование 👎 за удаление**:
- Бот отслеживает реакции в топиках-плейлистах
- Когда ВСЕ участники чата поставили 👎 на сообщение с треком → бот удаляет это сообщение
- Считать через message_reaction_updated хэндлер aiogram

**Команды**:
- /topics — управление: переименовать, удалить, создать новый
- /settings — качество по умолчанию, приоритет платформ

**Режим ЛС**: поиск/распознавание/скачивание прямо в чат. Можно привязать группу-библиотеку.

### 4.7 Entry Point (run.py)

Запуск веб-сервера и бота в одном event loop:
```python
asyncio.gather(
    run_web(),   # uvicorn FastAPI
    run_bot(),   # aiogram polling
)
```

## 5. Golden Rules (обязательно!)

1. **Типизация**: строгая. `any` запрещён. Используйте dataclasses и type hints.
2. **Валидация**: проверять все входные данные (query params, form data, callback data).
3. **Безопасность**: JWT httpOnly, bcrypt, никаких токенов в логах.
4. **Cleanup**: ВСЕГДА удалять скачанные файлы после отправки (try/finally).
5. **Error handling**: каждый внешний вызов (API, yt-dlp) в try/except с logging.
6. **Async**: всё async. Блокирующие вызовы (vk_api, spotipy) через run_in_executor.
